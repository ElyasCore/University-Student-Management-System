## University Student Management System

The biggest Java project I've built so far.

This project brings together pretty much everything I've learned up to this point, from arrays and 2D arrays to methods, loops, conditions, input validation, searching, and basic program state.

### Features

* Add multiple students
* Store names, ages, majors, and grades
* Show all students and their grades
* Search for a student by name
* Calculate a student's average
* Determine the student's letter grade
* Validate user input
* Handle cases where no students have been added

### Concepts Practiced

`Arrays` · `2D Arrays` · `Methods` · `Parameters` · `Return Values` · `Scanner` · `String` · `equalsIgnoreCase()` · `for` · `while` · `switch` · `if/else` · `boolean` · `Input Validation` · `Searching` · `Array Indexing` · `State Management`

Built as a bigger project to put all the Java fundamentals I've learned so far into one program before moving on to Object-Oriented Programming.
